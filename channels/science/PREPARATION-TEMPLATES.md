# Mẫu chuẩn bị theo thể loại

Đây là dàn ý chưa điền, không phải gói ready. Mọi loại vẫn cần episode.json, script.md, design.md, scene.tsx, checks.md, handoff.md và sources thật.

## explain
Câu hỏi: … / Điều kiện: … / Cơ chế: … / Bằng chứng: … / Giản lược: …
Hình: quan sát → mô hình/mặt cắt → nguyên nhân → kết quả. Mốc kiểm tra: không đảo chiều nguyên nhân và kết quả.

## tutorial
Mục tiêu: … / Kiến thức hoặc dụng cụ cần có: … / Các bước: … / Kết quả đúng: … / Lỗi và cách nhận biết: …
Ghi từng bước đã làm thử hay chưa. Hình thể hiện thao tác, không chỉ danh sách chữ.

## news
Ngày sự kiện: … / Ngày bài nguồn: … / Kiểm tra lần cuối: … / Điều thực sự mới: … / Bằng chứng gốc: … / Bất định: …
Trước sản xuất kiểm lại tin và cập nhật ledger. Không khẳng định ứng dụng đã có nếu mới là nghiên cứu ban đầu.

## paper-review
Tên/DOI: … / Loại bài: … / Toàn văn đã đọc hay chỉ tóm tắt: … / Câu hỏi: … / Mẫu và phương pháp: … / Một kết quả: … / Giới hạn: … / Ý nghĩa trong phạm vi bằng chứng: …
Ghi vị trí trang/hình/bảng hỗ trợ mỗi claim. Nếu chỉ có abstract thì không suy diễn methods hoặc limitations. Hình vẽ lại cần đúng đơn vị và nguồn dữ liệu.

## scientific-writing
Loại bài/đối tượng: … / Vấn đề cụ thể: … / Ví dụ trước: … / Ví dụ sau: … / Vì sao sửa: … / Nguồn hướng dẫn: …
Ví dụ tự tạo ghi giả định; không bịa số liệu, tài liệu tham khảo hoặc kết quả để hoàn thiện bài.
